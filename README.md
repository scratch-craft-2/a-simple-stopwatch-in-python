# Как установить?
## Windows
1. Для удобства установим git коммандой:
   ```
   winget install Git.Git
   ```
2. Склонируем репозиторий:
   ```
   git clone https://github.com/scratch-craft-2/a-simple-stopwatch-in-python
   ```
3. Заходим в папку:
   ```
   cd a-simple-stopwatch-in-python
   ```
4. Запускаем:
   ```
   python
   ```
