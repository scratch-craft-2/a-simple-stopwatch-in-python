# Как установить?
## Windows
1. Для удобства установим git коммандой:
   ```
   winget install Git.Git
   ```
2. Скачаем саму программу:
   ```
   git clone https://github.com/scratch-craft-2/a-simple-stopwatch-in-python
   ```
3. Заходим в папку:
   ```
   cd a-simple-stopwatch-in-python
   ```
4. Запускаем:
   ```
   python "простой секундомер.py"
   ```
## Linux
1. Установим Python и Git, тут все зависит от вашего дистрибутива.
   Debian подобные системы:
   ```bash
   sudo apt install git python-is-python3
   ```
   ArchLinux:
   ```bash
   sudo pacman -Sy git python
   ```
   А на других дистрибутивах вам придётся использовать свой пакетный менеджер
2. Склонируем репозиторий (см Windows/2)
3. Зайдем в папку:
   ```bash
   cd a-simple-stopwatch-in-python
   ```
4. Запустим программу:
   ```bash
   python "простой секундомер.py"
   ```
   или
   ```bash
   python3 "простой секундомер.py"
   ```
   или
   ```bash
   python простой\ секундомер.py
   ```
   или
   ```bash
   python3 простой\ секундомер.py
   ```
